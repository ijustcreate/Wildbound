# Dottie donor motion transfer — llama

**Status:** implementation draft; not approved by the player. This is an animation-only transfer. Existing Wildbound llama pixels, palette, shape, behavior and editable joint rig stay in place.

## Source and sequence evidence

- Wowhead NPC **151788, Dottie**; M2 **FileDataID 2734738**; source URL `https://wow.zamimg.com/modelviewer/live/m2/2734738.m2`.
- Local source used to create the native clip data: `test-output/wow-motion-audit/2734738.m2`.
- SHA-256: `18fb5b07708bea2a238cf06b5a2fd0752f57779cd72682c95cad46573e5cab7c`.
- Parsed source: M2 v274, 70 bones, 1,773 embedded vertices and 47 sequences. For v274, vertex bone indices directly address `bones[]`; the donor's `boneCombos` lookup is not applied to those weights.
- Transferred unique, non-alias sequences only: Stand (sequence 3, animation ID 0, 2,000 ms), Walk (sequence 5, ID 4, 1,200 ms), and Run (sequence 0, ID 5, 600 ms). Clips are sampled at 24 fps into 48, 29 and 15 editable keyframes. Their root displacement after reference-pose subtraction measured 0 source units on all axes.
- Alias entries are inventoried with their resolved sequence in generated `src/llama-wow-motion-data.mjs`; aliases are not registered as duplicate actions.
- Donor AttackUnarmed (ID 16), Death (ID 1) and swim (IDs 41–45) are intentionally not mapped. The llama's authored `spit-warning`, `kick`, `trot`, `attack`, `hurt` and `death` clips remain. A visually plausible donor track is not enough evidence to equate those actions.

## Retarget map and limits

The importer is reproducible with `node scripts/import-llama-wow-motion.cjs`. It maps source +X forward, +Y left, +Z up into Wildbound X/Y/Z as `[sourceY, sourceX, sourceZ]`, subtracts every mapped joint's own frame-zero pose and removes root motion on all three source axes. A scale of **10** was chosen after the first eight-facing preview showed the initial 20-unit scale driving hooves outside the compact Wildbound silhouette. Donor pelvis/chest/neck/head use bones 4/3/5/13. The four source limb chains reduce to the existing Wildbound shoulder/elbow/paw and hip/knee/paw joints; ears use bones 21/22 and the short target tail uses bones 12/18. Muzzle and eyes inherit head bone 13. This is positional animation retargeting, not donor mesh skinning; it is limited by the target rig's smaller silhouette and fewer helper joints.
