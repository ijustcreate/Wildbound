# Wildbound 1.0.66 — paper doll, lobby storage and 2D treasure

User requested the thinner paper-doll inventory, one-row actions, working lobby storage portal, TV/2D inventory and board-input repairs, seamless parallax, improved question blocks, a finish treasure chest, a small rightward lobby difficulty-totem move, a GitHub push and a new build/launcher. Parent main was 684506239bcd6fbcf4644abc2fd771ff79e58985 (1.0.65). Existing normal-profile saves, authored rigs and running 1.0.65 processes were not replaced or stopped.

## Changes and causes

- Inventory is bounded to 480 CSS pixels instead of 560. Eleven gear slots surround a centered animated portrait on all four sides; the directional graph follows the ring. Eight persistent actions occupy one row. Narrow/co-op panels scroll that row horizontally without wrapping or losing controller shortcuts. Selection does not resize the UI. Gear tooltips leave the doll visible; empty slots and unavailable actions stay visible.
- Lobby inputFrame previously omitted the portal binding, and practice clones deliberately suppressed portal/storage operations. A scoped lobby-storage context now uses actual heroes/chests, renders real portals, runs shared room/station movement, and restores expedition coordinates before saving. Chest-opening input cannot also withdraw the first item. Returning by room UI or controller restores the lobby position. Storage suppresses readiness/countdown. Room rendering has a fallback Animator because the main expedition renderer may not exist yet.
- TV participants now have owned inventory input, repeat navigation, equip, sockets, salvage and gear/stack drops. Drops use the TV loot list and retain sockets rather than appearing in the unrelated top-down world. Jump no longer inherits the normal game's bottom-face attack. Board rolls require a fresh, grounded, facing strike; held attacks during the board reveal cannot reroll. One player's open inventory pauses that hero, not other participants.
- Wide TV viewports paint the complete sky, ground and UI; cached parallax silhouettes wrap across both tile edges. Landscape seed is independent of gameplay RNG, and three layers are cached rather than rebuilt. Camera/projectile culling accounts for the wider view. Owner equipment is rendered live, with default appearance fields merged after owner data so partial appearances cannot crash rendering.
- Question blocks use cached 32-pixel framed/riveted pixel art and a readable question mark. First hit releases one lootable purple strange mushroom (unknown use) and 12 short-lived shards. Used blocks remain solid. Shards compact in place and are capped at 128; visible effects/items/blocks are culled.
- Finishing the 48-space TV world creates one shared level-scaled treasure pool using the existing victory reward system (3 + 2 items per participant, up to six players). Victory is safe from further enemy damage. The chest is rendered beside the exit and opens on interact instead of immediately resetting to lobby. Loot transfers into actual heroes and persists. Reopening or another player's panel cannot regenerate rewards; full backpacks leave items in the chest. Return is enabled only after the chest is empty and requires a fresh confirm/interact. Returning closes party panels and retains selected heroes. The 24-slot treasure grid uses six columns/four rows so short windows retain visible slots plus the return button. TV rewards do not overwrite normal expedition victory rewards and TV runtime state is not serialized.
- Lobby difficulty totem and its collision footprint move 30 world pixels right. Interaction and arrow-impact tests follow the new position.
