Its cursor is shared by the party, saves with the expedition, stops at the end of the current event list (70 default cards), restarts on respawn, and clears for a fresh expedition. A hit consumes the attack so it cannot also roll the original table. Held attack uses the game's existing release-to-strike control; attack cooldown prevents duplicate dispatch. Controller attacks prioritize the test board over nearby interactable props.

Test dispatch bypasses biome and starting-area eligibility while preserving ordinary spawning rules. Creatures prefer their required terrain where available and fall back to ordinary spawn positions on incompatible maps. Wells and crypt entrances can be tested outside their native biomes, and consecutive mystery cards can replace the active mystery. Existing terrain is retained, so terrain-specific effects still depend on the map. Existing creatures remain when the next event spawns. Test dispatch does not change pawn progress, rolls, turn order, rounds, dice state or the normal event director's history. Event effects/rewards remain real gameplay effects.
