# Lobby TV expansion — 1.0.46

Scope: the small lobby television platformer only. Main expedition jumping and combat are unchanged.

- Original opening scene plus 13 additional section layouts, joined on safe ground boundaries. Seeded shuffled bags select later scenes.
- Collectible coins and a shared coin counter on the TV. Coins cannot be collected twice in a session.
- Goomba-style walking/stompable enemies. Red mushrooms grant protection from one enemy hit, shown by a light outfit; falling still respawns the player.
- Two jump presses before landing, with button-release gating. No third airborne jump.
- Camera movement waits for a stationary trailing co-op player. Screen boundaries clamp horizontal motion instead of teleporting the trailing player. Pit deaths retain safe respawn placement.
- Down while standing on a green pipe takes the whole TV party underground. The room has 24 coins and a return pipe; Down (or Up) on that pipe returns everyone to the entrance. Each entrance remembers collected room coins until reset.
- TV controls swapped: standard face index 1 jumps (Xbox B / Nintendo A); index 0 runs (Xbox A / Nintendo B). Keyboard X jumps, Z runs; arrow keys move/use pipes. Lobby/main-game button mappings remain unchanged.

Verification: `tests/lobby-tv.test.mjs` covers deterministic scene variety, terrain seams, coins, mushroom damage protection, stomps, double jump, co-op camera/edges, swapped input routing and party pipe round trips. `scripts/verify-lobby-tv.cjs` draws overworld/underground views in isolated Electron and saves an ignored preview to `test-output/lobby-tv-preview.png`. Real-controller playtesting is still needed.

The earlier universal shared-prompt icon request is not integrated by this TV update; generated candidate assets remain separate. Source is not pushed automatically.
