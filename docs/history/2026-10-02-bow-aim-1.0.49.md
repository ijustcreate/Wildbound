# Bow aim transitions — 1.0.49

Visual-only exponential blends smooth bow raise/lower and facing rotation. Actual firing input and aim vector remain immediate. Pose interpolation and bow limb interpolation share the raise blend. Holding aim without charge now selects a raised draw frame instead of the first draw frame.

Bow-equipped rendering uses animated depth instead of a static saved rig layer list; other equipment retains authored ordering. Bow and quiver torso constraints remain in place. The visual bow handle also follows smoothed projection for arrow-origin alignment.

Tests: `tests/bow-aim-blend.test.mjs` covers frame-rate independence, non-mutating shot direction, aim hold and intermediate hand poses. `scripts/verify-bow-aim.cjs` renders 40 transition/facing combinations in isolated Electron to `test-output/bow-aim-preview.png`. These were visually inspected. Real controller motion still requires user playtesting. The previously reported unrelated full Electron smoke failures are not claimed fixed.

Includes the earlier unpushed 1.0.48 ready-pose work. No saves, rig artwork or Windows security settings changed.
