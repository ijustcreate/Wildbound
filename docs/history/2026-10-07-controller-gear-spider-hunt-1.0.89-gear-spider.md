# Controller gear and adult spider hunting — 1.0.89-gear-spider

Base Git commit: `1ce158a4108f3905a04390af18c57c040d4e6a3f` on modified `main`. The separate 1.0.87 and 1.0.88 desktop games were running during this work and were left untouched; this version uses a distinct package directory. The subsequent source push contains this feature and the silent-testing rule; the 1.0.89 package was built from the broader modified checkout and is not a build of that isolated commit.

The existing `use` and `equip` actions already called `unequip` for the selected gear slot, including the linked second hand of a two-handed weapon. The issue needed verification through the actual controller input path and clearer presentation: the selected-slot tooltip could override a hovered equipped slot, and the linked offhand did not carry the primary hand's socket metadata in the UI. Hover and focus now hold their own tooltip until they leave; controller navigation still changes the selection tooltip. Equipped items display their item details and the controller/keyboard unequip hint. The visible Unequip action returns the item to the first free backpack slot, preserves sockets, and reports a full backpack without losing the item.

Adult spiders previously moved toward their web and their prey in the same tick. These opposing moves pinned them at the web boundary. Pursuit now applies only when prey is within the creature detection radius and a bounded distance beyond the web. With no reachable target, the adult paths back toward its web. Blocked movement uses the existing navigation pathfinder; eggs, juvenile spiders, insect combat and web slow behavior remain on their existing paths.

Focused Node tests cover primary and Equip actions in lobby and expedition, first free slot, full bags, two-handed weapons, sockets, adult pursuit, wall routing, detection, and return to the web. Isolated Electron checks use the real input frame with simulated Xbox, Switch and PlayStation pads. They also inspect mouse hover, controller selection, linked gear, the visible Unequip button and tooltip bounds at 1280×850 and 600×430. Those checks use an isolated profile; physical controller hardware was not tested.
