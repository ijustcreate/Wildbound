# 1.2.0 — Offline local worlds and playable rig studio

Branch: `Wildbound_worlds`, based on the reconciled `wildbound-laptop` tree so committed gameplay/art and desktop fixes are preserved. Hosted server files, connection controls, tunnels and the old Heartwood journey portal are removed from this branch; existing branches and private data are retained. Multiplayer is a dormant adapter. The normal desktop profile is unchanged.

Local worlds now own authoritative state. Added seeded terrain/scenery deltas, independent named world directories, atomic queued checkpoints with recovery backups, reopening/catch-up clock, regional statistical ecology, bounded nearby actors and dormant distant actors, local predation/population growth, regrowth, daily director events, nest/settlement interactions, discovery quests, four native content packs and validated local pack installation with artwork/audio overrides. See `docs/LOCAL_WORLDS.md` for the current model and explicit limits.

Rig studio keeps hierarchy, centered reduced-width editing stage, inspector and playable preview side by side, with timeline below. A collapsed small-window row was caught by visual review and fixed with explicit minimum row height. Verification now asserts usable panel heights and timeline separation at 1100×800 as well as the wider layout. Preview has an empty lobby floor, compact toolbar, keyboard capture/release, controller selection/input ownership, live edited rigs and wheel zoom.

Verification: dedicated local-world tests cover seed/time determinism, backwards clock, long absences, scenery/terrain/actor/quest persistence, cleared streamed chunks, regrowth after reopening, transactional inventory actions, corrupt-primary recovery, manifest/path rejection and normalized input. Electron worlds verification blocks network requests and exercises creation/save/reload, one-day advancement, real keyboard/controller movement and release, layout sizing and absence of board/furniture. Automated tests are muted and isolated. Physical controller hardware and extended manual ecosystem balancing remain user playtests.

Build: `dist/1.2.0/Wildbound-win32-x64/Wildbound.exe`. Desktop shortcut: `Wildbound Worlds (1.2.0).lnk`, targeting the repository's `Play Wildbound.cmd` with normal profile (no `--preview`). Inspect the sibling `wildbound-build.json` for exact source commit and dirty status. Generated packages and test profiles stay ignored; Git push does not upload a downloadable release.
