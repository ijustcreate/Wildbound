# Persistent Forest test — 1.0.136-persistent-forest-test

User requested a Servers editor tab, a first persistent Forest hosted on an Optima mini PC, and a way to enter through the game. Implemented the desktop prototype using an independent Node/Electron Node-mode server, a versioned atomic realm save, separate test-character records, capability keys for player/creator access, and server-owned movement/combat/inventory/loot.

Entry: lobby **Persistent Worlds** → Studio **Servers** → **Start Local Forest** → **Enter Forest** or **Enter as Creator**. Play toolbar provides Servers / Creator and Return Home. Return restores the suspended lobby/expedition without importing realm progress into campaign profiles. Servers exposes address/key/name, status, reconnect, save, dated backup, stop and a basic placement tool: named landmarks, moving the Keeper, enemy territories, immediate spawns and placement undo. This is not the full planned house World Map or terrain/building editor.

Realm seed 73129 contains Arrival Camp, Keeper's Clearing, Overgrown Ruin, the existing Keeper NPC dialogue/quests and one renewing panther territory. Uses the destination-preserving boundless forest generator. Empty realms sleep; detailed simulation and native region streaming run with connected explorers. Each client camera follows its own explorer. Stale inputs stop within 300 ms, realm board rolls cannot reset the world, and fallen explorers return to camp. Up to six clients, one persistent test character per client profile.

Normal server data: `%APPDATA%\wildbound\forest-server`. `server.json` holds port/keys; `forest.json` world and test character records; `.bak` previous successful save. Save on joins/disconnects/creator edits, every five seconds and on clean shutdown. Recovery is deliberate: stop the server, preserve the current file, copy a selected backup as `forest.json`, restart. Invalid saves fail without replacing existing files. A save-folder lock rejects competing servers.

Packaging keeps the regular desktop ASAR and also copies an external `forest-server-runtime` containing the matching server/src/ws modules, so detached Node mode does not depend on Electron's ASAR filesystem. Package root contains `Start Wildbound Forest Server.cmd`, which can be used for a user-configured Windows Startup shortcut. Server startup from the editor is detached and hidden; closing the game disconnects its client without stopping the forest.
