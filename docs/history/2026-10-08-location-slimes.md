# 1.0.118 location slimes

Added seven location-themed slime encounters: forest, desert, ice, temple, beach, graveyard, and house. Each event spawns three individually varied slimes. Native pixel sprites use the in-game editable art/render pipeline, with separate body, gel, highlights, eyes, and location details. The WoW NPC 222603 display model 114801 contributes motion only; source mesh/texture are not shipped. Transferred editable clips: idle, walk, run, hurt, attack, attack variation, and death. The rig is a separate top-level slime definition; prior authored rigs remain unchanged.
