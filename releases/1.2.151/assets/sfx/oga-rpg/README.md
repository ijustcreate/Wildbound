# Added CC0 RPG effects

These 23 original OGG files are selected from rubberduck's **80 CC0 RPG SFX** pack. The source page identifies the pack as CC0/Public Domain. The source files are kept in their original format and are decoded through the game's normal `GameAudio` mixer.

| Source file | Gameplay use |
| --- | --- |
| `blade_01.ogg`, `blade_02.ogg`, `blade_03.ogg` | Added as sword-swing variants in the existing attack cue. |
| `book_01.ogg` | Added to inventory/book open feedback. |
| `chain_01.ogg`, `lock_01.ogg`, `lock_02.ogg` | Added to door open/close and supply chest opening. |
| `creature_die_01.ogg` | Creature death cue variant. |
| `creature_hurt_01.ogg`, `creature_hurt_02.ogg` | Creature damage variants. |
| `creature_misc_01.ogg` | Creature spawn and nearby enemy movement feedback. |
| `creature_monster_01.ogg` | Creature attack cue variant. |
| `creature_slime_01.ogg` | Slime-family vocal/action variant. |
| `item_coins_01.ogg`, `item_coins_02.ogg` | Coin pickup cue. |
| `item_gem_01.ogg`, `item_gem_02.ogg` | Gem/loot pickup variants. |
| `item_misc_01.ogg` | Generic item pickup cue. |
| `item_stone_01.ogg` | Rock and stone impact. |
| `item_wood_01.ogg`, `wood_01.ogg` | Chest/wall and tree wood impacts. |
| `metal_01.ogg` | Shield/metal impact variant. |
| `spell_fire_01.ogg` | Fire/magic cast variation. |
