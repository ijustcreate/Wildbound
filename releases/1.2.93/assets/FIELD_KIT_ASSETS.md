# Field Kit 0.9 asset manifest

All assets below are locally authored pixel geometry. They ship with the application and require no downloads or API keys.

| Asset | Runtime source | Usage |
|---|---|---|
| Barricade item icon | src/item-art.mjs | Inventory, crafting and placed cover |
| Cinder wand identifying flame pixels | src/item-art.mjs | Distinguishes Cinder from the ordinary fire wand |
| Jade objective relic and ritual altar | src/field-art.mjs | Protect and disrupt objectives |
| Lost explorer | src/field-art.mjs | Rescue objective |
| Bramble stems, lure fruit and flash cross | src/field-art.mjs | Trap identity markers |
| Six party symbols | src/field-systems.mjs | World, HUD, minimap, portals and Field Kit |
| Side/rear caps, hoods, circlets and horns | src/wearable-art.mjs | Eight-facing equipment rendering |
| Armor straps, plates, belt, knee panels and rarity trim | src/wearable-art.mjs | Character equipment details |
| Freckles, scar and beard | src/wearable-art.mjs | Cosmetic face presets |
| Cape folds, idle sheath and belt relics | src/player-motion.mjs | Character animation and accessory display |
| Forest/desert mixed encounter art | Existing golem, archer, elemental and wolf rigs | New encounters reuse the established art language |
| Preset palettes and swatches | src/appearance.mjs | Character creation and later editing |

Verification sheets are generated into test-output/field-outfits.png and the existing eight-facing contact sheets. Field Kit screenshots are test-output/field-trail.png, field-storage.png, field-craft.png, field-look.png and field-settings.png.
