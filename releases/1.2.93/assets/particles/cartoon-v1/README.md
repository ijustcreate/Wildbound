# Original cartoon particle bases

Created with the built-in image-generation tool, then extracted with `scripts/slice-particle-atlas.cjs`. `atlas.png` is the original generated sheet; the sixteen 128px PNGs preserve true alpha. Runtime uses bounded 96px tinted canvases, not giant frame-by-frame effect sheets.

Prompt used:

> Use case: stylized-concept. Asset type: production 2D game particle texture atlas, not a mockup. Create one square transparent PNG sprite sheet, exactly 4 columns by 4 rows of equally sized cells with generous transparent gutters and each sprite centered entirely inside its cell. Original polished hand-painted cartoon VFX textures, clean silhouettes, luminous crisp cores with subtle alpha-soft edges, dramatic but readable at small game sizes. Mostly white/ivory/neutral silver so the game can tint sprites; gray shading for smoke. Row 1: four-point sparkle; long tapered light streak pointing up; rounded layered smoke puff; compact licking flame pointing up. Row 2: simple jagged leaf; branching lightning bolt segment vertical; thin hollow circular shockwave ring; hollow magic rune circle with simple geometric symbols. Row 3: heart; cute floating ghost wisp with dark eyes; irregular ink/blood splat with small droplets; water droplet with a highlight. Row 4: bright crescent slash with tapered tips; soft glowing orb; sharp comic-book explosion silhouette WITHOUT words; curling rose-like spiral smoke bloom. No text, letters, labels, grid lines, checkerboard, backdrop, logos or watermark. These are reusable individual base sprites to be animated by code, NOT fully composed effects and not an imitation of any branded asset pack. True transparent alpha background, including the insides of rings, and no sprite touching another cell.

Recipes/descriptions: `src/cartoon-fx-presets.mjs`. Preview/edit/save/export in Rig studio → Particles. Composition is animated in code; imagery is original, not copied from the referenced commercial packs.
