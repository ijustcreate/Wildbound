# Added ambient sources

All sources below are CC0. The runtime crossfades loop points in `GameAudio.ambient()` and controls level with the ambience bus.

| Bundled file | Source and use |
| --- | --- |
| `swamp.ogg` | LokiF, Swamp Environment Audio. [OpenGameArt](https://opengameart.org/content/swamp-environment-audio) |
| `dungeon_ambient_1_0.ogg` | JaggedStone, Loopable Dungeon Ambience. [OpenGameArt](https://opengameart.org/content/loopable-dungeon-ambience) |
| `beach_waves_01.flac`, `beach_waves_02.flac` | jasinski, submitted by qubodup, Beach Ocean Waves. [OpenGameArt](https://opengameart.org/content/beach-ocean-waves) |
| `desert-wind-06.mp3` | AI-generated Desert Wind 06. [SFXMint](https://sfxmint.com/sounds/desert-wind-06) |
| `blizzard-wind-04.wav` | AI-generated Steady Winter Blizzard Wind 04. [SFXMint](https://sfxmint.com/sounds/blizzard-wind-04) |
| `room-tone-54.wav` | AI-generated Quiet Interior Room Tone 54. [SFXMint](https://sfxmint.com/sounds/ambience-room-tone-54) |
| `night-ambience-01.wav` | AI-generated Night Ambience 01. [SFXMint](https://sfxmint.com/sounds/night-ambience-01) |
| `horror-wind-whisper-38.wav` | AI-generated Cold Drafty Whisper-Like Wind 38. [SFXMint](https://sfxmint.com/sounds/horror-wind-whisper-38) |

SFXMint describes these downloads as CC0 1.0 and permits commercial use. OpenGameArt pages identify the three source packs as CC0. Original downloaded formats are retained for runtime decoding.
