# Bat flight concept

Generated using the built-in image generation tool, then edited to remove background artifacts. Reference direction: the user's eight-direction pixel mannequin motion sheet. Selected output: bat-motion-concept-v1.png.

The sheet explores six wingbeat phases, five directional rows, an eight-direction wheel, articulated wings and separated body/head/ears/wings. It is concept art, not validated frame data. Version 0.3.7 implements a native articulated bat inspired by it, using shared pose evaluation rather than slicing these images.

Prompt: Create a clean Wildbound bat flight pixel-art motion sheet on dark indigo: compact plum body, separate pointed ears, gold eyes, pink wing membranes, wing-arm/finger joints; five rows of six wingbeat poses; eight-direction wheel; spread-wing skeleton and separated parts. Preserve consistent scale and pivots. No humanoids or copied branding. Cleanup: replace noisy background patches with opaque indigo, clean text, hide far-side eyes in back facings.
