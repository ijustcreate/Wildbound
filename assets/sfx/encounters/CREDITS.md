# Original Wildbound encounter cues

All 111 WAV files are original deterministic synthesized compositions created for Wildbound. No external audio samples, melodies or voices are used. Each card has its own fixed note sequence, rhythm, accents and texture. Recipes and scores: manifest.json. Reproduce: node scripts/generate-encounter-audio.mjs. Mono PCM 16 bit, 22050 Hz, peak limited to 0.72. The HTML review player has no autoplay.
